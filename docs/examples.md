# Examples

## 图片生成

```
/agent-compass 帮我生成个图
```

**输出：**
```
这个我建议用「图片生成」。

你要的是成图，不是设计稿，所以它最快。

也可以选：
1. 图片生成：最快出图
2. 小红书封面设计：更懂封面结构
3. Figma 可编辑设计稿：适合做模板

我建议第 1 个。继续吗？
```

**用户回复：** `用第一个`
